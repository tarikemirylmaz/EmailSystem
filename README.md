# Email System

A Java-based email management system developed using **Object-Oriented Programming (OOP)** principles.

## About the Project

This project simulates a basic email system where users can interact with email-related operations through a Java application.

The project was developed to practice software design, object-oriented programming, class relationships, and the separation of different responsibilities into multiple classes.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Java Swing
- Event Handling

## Project Structure

- `Email.java` - Represents email objects and their information
- `User.java` - Represents users of the email system
- `EmailProcessing.java` - Handles email-related operations and processing
- `EmailSystemm.java` - Main application and system logic
- `InboxView.java` - Provides the inbox interface
- `SendEmailView.java` - Provides the interface for composing and sending emails

## Features

- User-based email system
- Sending emails
- Viewing received emails
- Inbox management
- Graphical user interface
- Object-oriented class structure
- Separation of interface and application logic

## Software Design

The project separates different responsibilities into individual Java classes. This makes the application easier to understand, maintain, and extend.

The repository also includes an analysis report containing additional information about the system design and UML diagrams.
